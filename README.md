# a tiny meadow · Angelina

An interactive 3D business card: a floating patch of meadow you can drag and flip.

- **Front:** my name spelled in pastel flowers, a pond with ducks, a bunny, a sheep, a cat, butterflies, and a fluffy misty forest.
- **Back:** a QR code to my RedNote (小红书) profile, plus tappable **Red** and **ins** links.

Built with [three.js](https://threejs.org/) — the grass is shell-textured (32 stacked layers), everything else is procedural. Single `index.html`, no build step.

**Live:** https://angelinahyhuang.github.io/meadow-card/
